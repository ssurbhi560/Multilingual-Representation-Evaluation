## PM-India-Parallel-Corpus

The folder `Eng-Indic-Parallel` contains the raw parallel corpus downloaded from [PM India](https://data.statmt.org/pmindia/v1/parallel/).
It includes 13 files, each containing parallel sentences between English and one of the following Indian languages: Assamese, Bengali, Gujarati, Hindi, Kannada, Malayalam, Meitei, Marathi, Odia, Punjabi, Tamil, Telugu, and Urdu.
